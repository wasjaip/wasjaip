# ЦО / Pricing Platform

**Production-проект по автоматизации ценообразования, расчёта цен и интеграции ценовых данных между системами.**

> Исходный код, корпоративные данные, внутренние адреса, идентификаторы и схемы интеграций не публикуются. На этой странице приведено только высокоуровневое техническое описание проекта.

## Задача

Цель проекта — собрать в одном решении процессы, связанные с расчётом и управлением ценами:

- подготовка и очистка товарных данных;
- расчёт базовых и итоговых цен;
- работа со скидками, маржинальностью и региональными ценами;
- сценарии согласования изменений;
- подготовка данных для внешних систем;
- автоматизация передачи цен через интеграционный контур;
- формирование аналитических таблиц и печатных прайс-листов.

## Что реализовано

### Расчётный контур

Разработана логика массового расчёта цен для большого товарного каталога с учётом:

- товарных групп и сегментов;
- регионов и зон продаж;
- базовых цен и скидок;
- себестоимости и маржинальности;
- различных сценариев изменения цены;
- дополнительных бизнес-правил и ограничений.

Расчёты выполняются в Python с активным использованием `pandas` и SQL.

### Аналитическое приложение

Для пользователей реализован web-интерфейс на `Dash`, в котором доступны:

- расчёт и проверка цен;
- сравнение текущих и плановых показателей;
- фильтрация и анализ результатов;
- работа с региональными ценами;
- сценарии согласования;
- экспорт результатов.

### Data Engineering

Проект объединяет несколько источников данных и справочников. В рамках проекта реализованы:

- ETL/ELT-процессы;
- загрузка данных из PostgreSQL и MS SQL;
- преобразование и нормализация товарных данных;
- контроль качества данных;
- подготовка данных для дальнейшей публикации цен;
- хранение истории и служебных параметров расчёта.

### Интеграции

Для передачи рассчитанных цен во внешние системы используется событийный и сервисный контур:

- подготовка сообщений для `Kafka`;
- сериализация структурированных сообщений;
- REST-интеграции;
- запуск и оркестрация отдельных потоков обработки;
- контроль дат начала действия цены и версий данных.

### Автоматизация

В проекте используются инструменты автоматизации и эксплуатации:

- `Airflow` для задач обработки данных;
- `Docker` для изолированного запуска компонентов;
- `NiFi` для интеграционных потоков;
- SQL и Python-скрипты для служебных операций;
- автоматическое формирование Excel/PDF-выгрузок и прайс-листов.
