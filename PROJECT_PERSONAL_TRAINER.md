# 🎯 Персональный тренер ЕГЭ‑2027

**EdTech · Personalization · Analytics · Web Application**

Персональный тренер для подготовки ученика к ЕГЭ с отдельными кабинетами учителя и ученика, индивидуальными заданиями, отслеживанием прогресса и анализом ошибок.

Исходный код и рабочая инфраструктура не публикуются. Здесь описаны только продуктовая логика, архитектура и стек.

## Задача

Создать систему, в которой учитель управляет индивидуальной траекторией подготовки, а ученик видит назначенные задания, свои результаты и текущую готовность.

Ключевые сценарии:

- отдельные кабинеты учителя и ученика;
- персональное назначение тестов и материалов;
- индивидуальный план и календарь подготовки;
- хранение истории выполнения;
- анализ ошибок и динамики результатов;
- расчёт готовности ученика;
- отдельный контур для полноформатных вариантов;
- серверное хранение данных через API и PostgreSQL.

## Логика подготовки

Обычные тесты используются для тренировки и оценки текущей готовности. Полноформатный вариант вынесен в отдельный контур и отражает итоговый результат подготовки.

Материалы и задания могут назначаться учителем индивидуально. Рейтинг и итоговые показатели не смешиваются с обычными тренировочными тестами.

## Архитектура

```text
Teacher UI        Student UI
     \               /
      \             /
          REST API
             ↓
       Business Logic
             ↓
         PostgreSQL
```

Клиентские кабинеты отделены от серверной логики и базы данных. Назначения, результаты, история и показатели прогресса проходят через API.

## Стек

`Python` · `FastAPI` · `PostgreSQL` · `JavaScript` · `HTML/CSS` · `REST API` · `Analytics`

## Что реализовано

- Teacher / Student UI;
- загрузка учеников и заданий через API;
- персональное назначение тестов;
- календарь подготовки;
- хранение результатов и истории;
- показатели прогресса и готовности;
- работа с ошибками и результатами тестирования;
- отдельная логика полноформатных вариантов.

## Моя роль

Проектирование продукта и бизнес-логики, архитектура API и хранения данных, разработка и интеграция пользовательских кабинетов, тестирование сценариев и поэтапное развитие системы.
