# 🎯 Персональный тренер подготовки

**EdTech · Personalization · Analytics · Web Application**

Веб-сервис индивидуальной подготовки учащихся с разделением ролей учителя и ученика, персональными заданиями и отслеживанием прогресса.

Исходный код и рабочая инфраструктура не публикуются. Здесь описаны только продуктовая логика, архитектура и стек.

## Задача

Сделать систему, в которой учитель может управлять индивидуальной траекторией ученика, а ученик — видеть назначенные задания, результаты и текущий прогресс подготовки.

Ключевые сценарии:

- кабинеты учителя и ученика;
- назначение тестов конкретному ученику;
- персональный план подготовки;
- календарь подготовки на длительный период;
- учёт результатов выполнения;
- анализ ошибок и готовности;
- разделение обычных тестов и полноформатных вариантов;
- серверное хранение данных вместо зависимости от локального состояния браузера.

## Архитектура

```text
Teacher UI        Student UI
     \               /
      \             /
          REST API
             ↓
       Business Logic
             ↓
         PostgreSQL
```

Клиентские кабинеты отделены от серверной логики и базы данных. Назначения, результаты и прогресс проходят через API.

## Стек

`Python` · `FastAPI` · `PostgreSQL` · `JavaScript` · `HTML/CSS` · `REST API` · `Analytics`

## Что реализовано

- Teacher / Student UI;
- загрузка списка учеников через API;
- персональное назначение тестов;
- календарь подготовки;
- хранение результатов и истории выполнения;
- расчёт показателей прогресса и готовности;
- работа с ошибками и результатами тестирования;
- отдельная логика полноформатных вариантов.

## Моя роль

Проектирование продукта и бизнес-логики, архитектура API и хранения данных, разработка и интеграция пользовательских кабинетов, тестирование сценариев и поэтапное развитие системы.
