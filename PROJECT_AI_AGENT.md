# 🤖 Локальный AI Agent

**AI Engineering · Local LLM · Tool Use · Automation**

Локальный ИИ-агент для работы с файлами, задачами и корпоративными инструментами без обязательной передачи рабочего контекста во внешние облачные сервисы.

Исходный код и рабочие конфигурации не публикуются. На этой странице описаны только архитектурные решения и используемый стек.

## Задача

Создать локального помощника, который может не только отвечать на вопросы, но и выполнять прикладные действия через набор контролируемых инструментов:

- искать и читать локальные файлы;
- работать с проектной документацией;
- получать задачи и данные из Jira;
- создавать задачи и комментарии после подтверждения пользователя;
- сохранять журнал действий;
- разделять безопасные операции чтения и потенциально изменяющие действия;
- маскировать секреты и чувствительные значения в логах.

## Архитектура

```text
Пользователь
    ↓
Agent Core
    ↓
Local LLM
    ↓
Tool Router
    ├── Local files
    ├── Jira API
    ├── Search / context
    └── Action log
```

LLM отвечает за интерпретацию запроса и выбор инструмента, а выполнение операций вынесено в отдельный контролируемый слой.

Для действий, изменяющих данные, предусмотрено подтверждение пользователя. Чтение может выполняться автоматически.

## Стек

`Python` · `FastAPI` · `Qwen` · `Ollama` · `REST API` · `Jira API` · `Hugging Face` · `Local LLM` · `RTX 3090`

## Что реализовано

- локальный inference LLM;
- Agent Core с маршрутизацией инструментов;
- чтение, поиск и навигация по локальным файлам;
- интеграция с Jira;
- журналирование действий;
- режимы `auto / confirm` для разных типов операций;
- защита конфигурации и маскирование секретов;
- API-слой для подключения интерфейсов и внешних сервисов.

## Моя роль

Архитектура решения, развёртывание локальной LLM, разработка Agent Core, проектирование инструментов, интеграций и модели прав доступа.
